# FlavorDash 🍳

FlavorDash is a modern, responsive React Native mobile application built for food enthusiasts, home cooks, and students looking for quick, delicious meal inspiration. Powered by a live third-party public API, the app allows users to search global recipes instantly, browse through categorized lists with rich imagery, and view step-by-step cooking instructions.

## 🛠️ Tech Stack & Technical Features
* **Framework:** React Native (Expo)
* **API Integration:** Axios (`async/await`) fetching live data from **TheMealDB API**
* **Navigation:** `@react-navigation/native` (Stack Navigator for seamless screen transitions)
* **Layout & Styling:** StyleSheet utilizing Flexbox (`flexDirection`, `justifyContent`, `alignItems`, `padding`, `margin`) for cross-device responsiveness
* **State Management:** React Hooks (`useState`, `useEffect`) and custom hooks
* **Performance:** Optimized `FlatList` component for rendering dynamic recipe lists
* **UI Enhancements:** Expo Vector Icons (`Ionicons`) and responsive remote image components

---

## 📂 Planned Application Screens
1. **Home / Search Screen (`HomeScreen`):** Features a search bar and quick category navigation.
2. **Recipe List Screen (`ListScreen`):** Displays query results efficiently using a high-performance `FlatList`.
3. **Recipe Details Screen (`DetailsScreen`):** Shows complete ingredient checklists, featured images, and cooking instructions.
